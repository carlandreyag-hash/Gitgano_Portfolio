# Selected portfolio projects

This is an editorial shortlist based on local documentation and code inspection, not a runtime audit or assurance of production readiness. All 43 entries remain available in the full collection and navigation.

1. **BinWatch** — distinctive waste-management concept with map components and documented sorting, reporting, and eco-challenge workflows. Telemetry and AI claims have not been independently validated.
2. **LibroSmart** — clear documentation of authentication and catalog discovery, with honest limitations around local sample data and unfinished circulation features.
3. **BakeTrack** — demonstrates PHP backend development through concrete order, customer, ingredient, recipe, and product CRUD modules.
4. **DOSEVIA** — native notification scheduling and snooze implementation provide a useful platform-specific development example; native dependencies and delivery were not tested.
5. **RentEase** — distinct tenant and landlord dashboards with property, payment, and maintenance-request models; described as a prototype rather than a deployed rental service.
6. **CollabTrack** — task assignments, priorities, due dates, documents, and persistence modules demonstrate stateful workflow design. Sample team data remains illustrative.

The shortlist favors variety and visible implementation over project count. Duplicate calculators, starter examples, and ambiguous folders remain in All projects. Update `src/projectCatalog.ts` and the `featured` flags in `src/projects.json` to revise it.
